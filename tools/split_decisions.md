## Execution Notes

### ID conflicts (pre-existing standalone series)

Several author umbrella splits conflicted with series that already exist in
`series.yaml` with their own artist IDs and curations. These were accepted
under a prefixed ID but need manual reconciliation:

- **pippi_langstrumpf**: Already exists (85 albums, approved). Created
  `astrid_lindgren_pippi_langstrumpf` (20 albums from umbrella). The umbrella
  albums are likely duplicates/bleed. Need to merge or exclude.
- **ferien_auf_saltkrokan**: Already exists. Created
  `astrid_lindgren_ferien_auf_saltkrokan` (6 albums). Same situation.
- **die_wilden_huehner**: Already exists. Created
  `cornelia_funke_die_wilden_huehner` (7 albums). Same situation.
- **gespensterjaeger**: Already exists. Created
  `cornelia_funke_gespensterjaeger` (5 albums). Same situation.
- **raeuber_hotzenplotz**: Already exists. The Preußler umbrella split created
  `otfried_preussler_raeuber_hotzenplotz` (15 albums). Overlaps with the
  standalone `raeuber_hotzenplotz` series AND its kinofilm/mondrakete sub-splits.

**Action needed**: For each of these, decide whether the umbrella albums should
be merged into the existing standalone series or excluded from the umbrella.

### michael_ende
